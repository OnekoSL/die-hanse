# Roadmap

13. September 2026. Keine zugesagten Kalendertermine.

| Meilenstein | Ergebnis | Stand |
| --- | --- | --- |
| M0 | Planung öffentlich und erste Basis entschieden | Abgeschlossen |
| M1 | Eigenständiger Python-/React-/Tauri-Grundstand | Implementiert |
| M2 | Ganzzahlgeld, verbindlicher Handel und sichere Speicherplätze | Implementiert; automatisiert geprüft |
| M3 | Elf Städte, neun Waren, freie Fahrten, Karte, Kalender, Berichte und Bauzeiten | Implementiert; Browser geprüft |
| Alpha 0.1 | Windows-Installer und öffentliche Vorabversion | Veröffentlicht als `v0.1.0-alpha.1` |
| M4 | Bezahlte Verwalter und wiederkehrende Handelsaufträge | Anschließend separat planen |
| M5 | Jahreszeiten, Reisegefahren und Schutz | Später |
| M6 | Warenalter, Verderb und Veredelungspilot | Später |
| M7 | Bewusster Import alter A-/B-Spielstände, weitere Unternehmenssysteme | Später |
| M8 | Gemeinsame Backtest-Regeln, Langzeitbalance und Einführung | Später |

Gegenüber dem ersten Entwurf sind alle Städte, neun Grundwaren, Speicherplätze und Windows-Auslieferung vorgezogen. Verwalter sind keine Voraussetzung für die Alpha. Altimporte gehören nicht zu M2.

Zu jedem Meilenstein gehören Dokumentation, passende Tests und bei sichtbaren Änderungen eine Prüfung der echten Oberfläche. Grenzen der Abnahme werden ausdrücklich dokumentiert.
